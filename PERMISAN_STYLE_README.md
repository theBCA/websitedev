# Günpay Perde - Permisan Style Website

This is a modern, responsive website design inspired by the Permisan website structure, adapted for Günpay Perde with enhanced features and modern styling.

## 🎨 Design Features

### Modern Layout
- **Clean, professional design** inspired by Permisan's structure
- **Responsive grid system** that works on all devices
- **Modern typography** using Inter font family
- **Smooth animations** and hover effects
- **Professional color scheme** with blue accent colors

### Header & Navigation
- **Two-tier header** with contact information and main navigation
- **Sticky navigation** that stays at the top when scrolling
- **Dropdown menus** for organized content structure
- **Mobile hamburger menu** with smooth animations
- **Language switcher** (TR/EN)
- **"Teklif Talebi" (Quote Request)** button

### Hero Section
- **Gradient background** with modern styling
- **Two-column layout** with content and image
- **Call-to-action buttons** for user engagement
- **Responsive design** that stacks on mobile

### Content Sections
1. **Company Profile** - About the company
2. **Services** - What the company does (4 service cards)
3. **Products** - Product showcase with images and descriptions
4. **Social Responsibility** - Environmental commitment
5. **Brands** - Company information and contact details

### Footer
- **Three-column layout** with organized links
- **Company information** and legal links
- **Responsive design** that adapts to screen size

## 🚀 How to Use

### 1. Open the Website
Simply open `permisan-style.html` in your web browser to view the website.

### 2. Navigation
- **Desktop**: Use the main navigation menu at the top
- **Mobile**: Click the hamburger menu (☰) to access navigation
- **Smooth scrolling**: All internal links use smooth scrolling

### 3. Interactive Features
- **Hover effects** on cards and buttons
- **Mobile menu** with animated hamburger icon
- **Language switcher** (TR/EN buttons)
- **Quote request** button that scrolls to contact section
- **Scroll animations** for content sections

## 🔄 Updates and Maintenance

### Adding New Content
1. **New sections**: Add to HTML and corresponding CSS
2. **New products**: Add to products grid in HTML
3. **New services**: Add to services grid in HTML
4. **Images**: Place in `images/` folder and update paths

### Styling Changes
- **Colors**: Update CSS custom properties
- **Layout**: Modify grid and flexbox properties
- **Typography**: Update font sizes and weights
- **Animations**: Adjust transition timings

### JavaScript Enhancements
- **New interactions**: Add event listeners
- **Animations**: Use Intersection Observer API
- **Forms**: Add form handling logic
- **Performance**: Optimize scroll and resize events
